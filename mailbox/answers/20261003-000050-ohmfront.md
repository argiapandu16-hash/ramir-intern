# Answer: ohmfront — checkout button a11y
# asked: 2026-10-03 00:00 (phone) · answered: 2026-10-03 (sandbox, ohmfront/a11y-audit)

## Verdict: almost certainly NOT accessible ❌
Small grey text on a button fails the two checks that matter:

1. **Contrast (WCAG 1.4.3, AA)** — normal-size text needs **≥ 4.5:1**.
   Typical "small grey" (`#999` on white) is only **~2.9:1**. Fail.
   Rule of thumb: if it looks light-grey on white, it fails.
2. **Target size (WCAG 2.5.8 AA)** — minimum **24×24 px**, Apple HIG says
   **44×44 pt**. A "small" button usually misses both.

## Fix (smallest-first)
1. Darken the label until contrast ≥ 4.5:1 (e.g. `#595959` on white = 7:1 ✅).
   Verify free: WebAIM Contrast Checker / Stark plugin.
2. Min touch target 44px height, full-width on mobile checkout.
3. Never signal state by color alone (disabled = grey + "Unavailable" text).
4. Visible focus ring (`:focus-visible` outline) for keyboard users.
5. Use a real `<button>` (not div) so TalkBack/VoiceOver announces it.
6. Test on your phone: TalkBack ON → swipe to the button → it must read
   label + role + state.

## Score: 3/10 — readable by you, invisible to many.
One darkening pass + 44px target gets it to 8/10 in ten minutes.
